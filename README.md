# Fabrikam Manufacturing – Microsoft Fabric Analytics

This repository implements an end-to-end data engineering and analytics solution
using Microsoft Fabric for a global manufacturing enterprise.

## Key Capabilities
- Centralized Lakehouse (Bronze / Silver / Gold)
- Real-time operational analytics
- Supply chain analytics
- Fabric Data Warehouse
- Power BI dashboards

## Technologies
- Microsoft Fabric
- Fabric Lakehouse
- Fabric Data Pipelines
- PySpark Notebooks
- Fabric Data Warehouse
- Power BI
